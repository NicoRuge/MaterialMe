Einführung

Diese Datenschutzerklärung erklärt, wie die ICEinfo Android‑App ("die App") mit Informationen umgeht.

Keine Erhebung personenbezogener Daten

Die App erhebt, speichert oder verarbeitet standardmäßig keinerlei personenbezogene Daten von Nutzern. Es werden keine Namen, E‑Mail‑Adressen, Telefonnummern, dauerhafte Gerätekennungen oder sonstige personenbezogene Identifikatoren erfasst.

Standardmäßig verwendet die App keine Analyse‑Tools, Werbenetzwerke, Tracker oder Cookies. Eine optionale Ausnahme ist das Crash‑Reporting, das ausschließlich nach aktiver Zustimmung des Nutzers aktiviert wird (siehe Abschnitt „Crash‑Reporting").

Datenquellen & Netzwerkverwendung

Die App ruft Informationen von einer externen API ab, die von DB Systel GmbH betrieben wird. Die API‑Anfragen erfolgen nur, wenn das Gerät mit dem Bord‑WLAN der deutschen ICE‑Züge (betrieben von DB Fernverkehr AG) verbunden ist.

Zusätzlich ruft die App Abfahrtsdaten für Anschlussbahnhöfe von der öffentlichen API v6.db.transport.rest ab, einem unabhängigen Community‑Dienst auf Basis der DB‑Daten.

Die App lädt keine Nutzerdaten oder persönliche Inhalte auf entfernte Server hoch. Netzwerkzugriffe dienen ausschließlich dem Abruf der angezeigten Daten.

Crash‑Reporting (optional, opt‑in)

Beim ersten Start der App und nach jedem Update wirst du gefragt, ob du anonyme Absturzberichte senden möchtest. Standardmäßig ist diese Funktion deaktiviert. Sie kann jederzeit in den App‑Einstellungen wieder ein‑ oder ausgeschaltet werden.

Falls aktiviert, sendet die App bei einem Absturz folgende Informationen über Firebase Crashlytics (Google Ireland Ltd.) an die Server von Google:

Stacktrace des Absturzes, App‑Version, Android‑Version, Gerätemodell, Sprache, verfügbarer Arbeits‑ und Speicherplatz, ungefähre Region (abgeleitet aus der IP‑Adresse) sowie eine zufällig generierte Installations‑ID. Diese Installations‑ID ist nicht mit deinem Google‑Konto oder anderen persönlichen Identifikatoren verknüpft.

Diese Daten werden ausschließlich zur Stabilitäts‑ und Qualitätsverbesserung der App verwendet. Sie werden nicht mit Dritten geteilt und nicht für Werbe‑ oder Profiling‑Zwecke verwendet. Rechtsgrundlage ist deine ausdrückliche Einwilligung gemäß Art. 6 Abs. 1 lit. a DSGVO, die du jederzeit widerrufen kannst.

Weitere Informationen zur Datenverarbeitung durch Firebase Crashlytics: firebase.google.com/support/privacy

Dritte & Zugehörigkeit

Die API wird von DB Systel GmbH betrieben; das Bord‑WLAN wird in Zügen der DB Fernverkehr AG bereitgestellt. Die App ist unabhängig und steht in keiner Verbindung zu Deutsche Bahn AG oder deren Tochtergesellschaften. Erwähnungen dieser Organisationen dienen lediglich der Quellenkennzeichnung.

Datenspeicherung & Sicherheit

Da die App standardmäßig keine personenbezogenen Daten erhebt, erfolgt keine Speicherung solcher Daten. Bei aktiviertem Crash‑Reporting werden die oben genannten Daten verschlüsselt (HTTPS) an Firebase übertragen und gemäß den Aufbewahrungsfristen von Google Firebase Crashlytics gespeichert (in der Regel 90 Tage für detaillierte Crash‑Reports). Die Sicherheit und Verfügbarkeit des Bord‑WLANs sowie der APIs liegen in der Verantwortung der jeweiligen Betreiber.

Kinder

Die App richtet sich nicht an Kinder unter 16 Jahren und erhebt nicht wissentlich personenbezogene Daten von Kindern.

Introduction

This Privacy Policy explains how the ICEinfo Android app ("the App") handles information.

No Collection of Personal Data

By default, the App does not collect, store, or process any personal data from users. The App does not collect names, email addresses, phone numbers, persistent device identifiers, or any other information that can be used to identify an individual.

By default, the App does not use analytics, advertising networks, trackers, or cookies. An optional exception is crash reporting, which is only enabled after the user explicitly opts in (see the "Crash Reporting" section).

Data Sources & Network Use

The App retrieves data from an external API operated by DB Systel GmbH. These API requests are made only when the device is connected to the onboard Wi‑Fi on German high‑speed trains operated by DB Fernverkehr AG.

In addition, the App retrieves departure board data for connecting stations from the public v6.db.transport.rest API, an independent community service built on DB data.

The App does not upload user content or personal information to remote servers. Network requests are limited to fetching the data displayed in the App.

Crash Reporting (optional, opt‑in)

On first launch and once after every app update, you are asked whether you want to send anonymous crash reports. This feature is disabled by default. It can be toggled on or off at any time in the App's settings.

If enabled, the App sends the following information via Firebase Crashlytics (Google Ireland Ltd.) to Google's servers when a crash occurs:

The crash stacktrace, app version, Android version, device model, language, available RAM and storage, approximate region (derived from the IP address), and a randomly generated installation ID. This installation ID is not linked to your Google account or any other personal identifier.

This data is used exclusively to improve the stability and quality of the App. It is not shared with third parties and not used for advertising or profiling purposes. The legal basis is your explicit consent under Art. 6(1)(a) GDPR, which you may withdraw at any time.

More information on data processing by Firebase Crashlytics: firebase.google.com/support/privacy

Third Parties & Affiliation

The external API is operated by DB Systel GmbH and the onboard Wi‑Fi is provided on trains operated by DB Fernverkehr AG. The App is independent and is not affiliated with Deutsche Bahn AG or any of its subsidiaries. References to those organizations are solely to identify data sources and network providers.

Data Retention & Security

Because the App does not collect personal data by default, there is no user personal data retention. When crash reporting is enabled, the data listed above is transmitted to Firebase over HTTPS and stored according to Google Firebase Crashlytics retention policies (typically 90 days for detailed crash reports). The security and availability of the onboard Wi‑Fi and the APIs are controlled by the network and API operators.

Children

The App is not directed to children under 16 and does not knowingly collect personal data from children.
